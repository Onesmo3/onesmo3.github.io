# MbiseCAD website

A responsive, static portfolio website with dark/light theme switching.

## Publish with GitHub Pages
1. Create a **public** repository named `Onesmo3.github.io` under the GitHub account `Onesmo3`.
2. Upload `index.html` to the repository root and commit the change.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait a few minutes and open https://onesmo3.github.io

Update the project cards in `index.html` when you have verified direct APK release links.
